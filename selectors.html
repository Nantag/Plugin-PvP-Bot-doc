Selectors

How to point one command at one bot, many bots or all of them.

Most orders take a selector in place of a bot's name. It works the same everywhere: follow, retreat, hide, tether, tp portal/pearl/rift, path assign/stop, faction join, kit give and kit givefaction. The command list writes it as <selector>.

List#

SelectorWho it picks
<name>One bot, by name.
allEvery active bot.
latestEvery bot from the last spawn command that is still around.
faction <name>A faction's active bots.
overfaction <name> or of <name>The active bots of every faction in a coalition.
randomOne bot at random.
random[filters]Random bots that pass every filter (see below).
list:a,b,cAn explicit list of names. Mostly used by scripts.
Commands with fewer options guard, pause, resume and the instant tp only take <bot>, all or faction <name>. follow stop and guard stop take a name or all.

random[...]#

Picks at random among the bots that pass every filter. Filters are key=value pairs separated by commas; spaces after the commas are fine.

FilterMeaning
limit=<n>How many bots at most (default 1).
nofaction=true|falseOnly bots with no faction, or only bots in one.
paused=true|falseOnly paused bots, or only running ones.
world=<name>Only bots in that world.
alreadyhaskit=true|falseOnly bots already carrying something, or only empty-handed ones.
alreadyhaskit is an approximation The plugin doesn't record which kit a bot was given, so the filter only checks whether the inventory is empty. A bot that picked an item up off the ground counts as "already has a kit".

Examples#

/pvpbot kit give iron random[limit=5,alreadyhaskit=false]
/pvpbot faction join bandits random[limit=3, nofaction=true]
/pvpbot tp pearl random[limit=10,world=world] Steve 30
/pvpbot follow faction red Steve circle
/pvpbot retreat overfaction north to 100 64 -250
/pvpbot hide latest
