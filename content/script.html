A cosa servono

Preparare uno scenario richiede sempre gli stessi comandi: crea i bot, mettili in una fazione, dai i kit, mandali contro qualcuno. Uno script li salva sotto un nome, e poi basta una riga per rifarli tutti.

Esempio

/pvpbot script create raid
/pvpbot script add raid pvpbot spawn 20
/pvpbot script add raid pvpbot faction join {1} latest
/pvpbot script add raid pvpbot kit givefaction {2} {1}
/pvpbot script add raid wait 40
/pvpbot script add raid pvpbot faction hostile {1} player

E per lanciarlo:

/pvpbot script run raid banditi ferro

Crea 20 bot, li mette nella fazione banditi, dà loro il kit ferro, aspetta due secondi e poi li mette in guerra con i giocatori.

Regole

  • Parametri: {1}…{9} vengono sostituiti con gli argomenti dati a script run, nell'ordine.
  • Pause: una riga wait <tick> ferma lo script e riprende il resto dopo quei tick (20 = 1 secondo). Il server intanto va avanti normalmente.
  • latest: dentro uno script indica i bot creati da questo script con l'ultimo spawn, anche se nel frattempo qualcun altro ha creato altri bot.
  • Barra iniziale: le righe si scrivono senza /; se la metti viene tolta.
  • Commenti: le righe che iniziano con # vengono saltate.
  • Limite: 200 righe per script.
  • Uno alla volta: se lanci uno script mentre un altro è in corso, parte appena il primo finisce. Così due script non si rubano i bot a vicenda.
  • Permessi: le righe vengono eseguite come se le scrivessi tu. Uno script fa risparmiare tempo, ma non dà permessi in più.
Bot con nome negli script /pvpbot spawn <nome> cerca la skin in background, quindi la riga dopo potrebbe non trovare ancora il bot. Negli script usa /pvpbot spawn <nome> none, che crea il bot subito.

Gestione

ComandoCosa fa
/pvpbot script listElenca gli script.
/pvpbot script show <nome>Mostra le righe numerate.
/pvpbot script remove <nome> <riga>Toglie una riga (numero come in show).
/pvpbot script delete <nome>Cancella lo script.

Gli script stanno in plugins/PvpBot/scripts.yml. Un /pvpbot reload ferma gli script in corso.
