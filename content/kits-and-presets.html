Kits

A kit is a snapshot of an inventory: hotbar, inventory, armour and offhand, and the ender chest that goes with it. Enchantments, names and every item component survive (shield banner patterns included).

/pvpbot kit save diamond
/pvpbot kit save mace Marco
/pvpbot kit edit diamond
/pvpbot kit rename diamond diamond_v2
/pvpbot kit list
/pvpbot kit delete diamond

The first command saves your inventory, the second saves the bot Marco's. kit edit opens the kit editor: the kit laid out like an inventory, with a second page for its ender chest (a new name makes a new, empty kit). kit rename renames it, and faction kit tables follow the new name.

Giving a kit

/pvpbot kit give diamond Marco
/pvpbot kit give diamond Steve
/pvpbot kit give diamond latest
/pvpbot kit givefaction diamond bandits
  • give takes a bot, a real player (handy to spar on equal terms) or a selector.
  • givefaction takes a faction name or a selector.
  • The kit replaces whatever the receiver was carrying.
  • A bot remembers the kit it was given, and regears back up to it.

To hand out different kits at random inside a faction, use per-faction kit tables.

Moving kits.yml between servers Items are saved in the format of the server that created them. A kits.yml copied from a server on a different build may fail to load: PvpBot then starts without kits and says so in the console. Make the kits again on the new server.

Presets

A preset is a named set of settings applied to every bot on the server in one go. (The six difficulty presets, /pvpbot difficulty preset, only set the skill knobs; these set anything.)

/pvpbot preset
/pvpbot preset sweaty
/pvpbot preset off

With no name it shows the active preset and the ones available. With a name it applies it. off goes back to config.yml as written.

A preset sits above config.yml but below faction settings. A faction you tuned by hand stays as it is when you change preset.

Built-in presets

PresetForWhat it sets
casualBeginners: slow, sloppy bots.skill 25, miss-chance 30, mistake-chance 35, attack-cooldown 18, reaction-ticks 60; no crits, pearls or cobwebs.
easyA beginner: slow, misses a lot.Every knob around 10–15; no webs, pearls, shield breaking, reads or tricks; the old healing.
normalAn average player.Knobs around 35–40; the basics: crits, jump resets, shield and axe, webs, pearls; few reads.
hardA good player.Knobs around 55–60; hit select, crit chains, reads you, predicted and head webs, the damage model, edge play, elytra mace.
expertA sweat.Knobs around 75–80; every trick on: hit-webs, d-taps, whiff punishes, chained elytra mace, weapon swapping, cart PvP, a 25 ms connection.
sweatyEverything on and sharp, but still human.skill 85, miss-chance 3, mistake-chance 5, attack-cooldown 10, ping 25 ms, reaction-ticks 8; crits, axe against shields, buff potions, cobwebs, pearl launch, weapon swapping, elytra mace and cart PvP.
passiveScenes and training dummies.They don't look for targets, don't wander and don't fight other bots; they only hit back when hit.

Anything a preset doesn't name comes from config.yml.

Making one

/pvpbot set skill 70
/pvpbot set pearls false
/pvpbot preset save tournament
/pvpbot preset tournament

preset save saves the values in force right now, including any preset already active. To edit a preset: apply it, change what you want with /pvpbot set, and save it again under the same name. /pvpbot preset delete <name> deletes it.

Presets live in config.yml under presets: and can be written by hand too, using the same names as /pvpbot set.
