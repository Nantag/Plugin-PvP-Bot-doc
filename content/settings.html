Changing settings

  • In game: /pvpbot set <name> <value>. Applies to every bot at once and is written to config.yml.
  • For one faction: /pvpbot faction set <faction> <name> <value>. Applies only to that faction's bots.
  • In the file: edit plugins/PvpBot/config.yml, then run /pvpbot reload.
  • To see them: /pvpbot settings, or /pvpbot settings combat for one group, or /pvpbot settings pearl to filter by name.

Values outside the limits are refused. Times are in ticks (20 ticks = 1 second), distances in blocks, and health in half-hearts (20 = full health).

Which value wins

When a bot reads a setting, the most specific layer wins:

  1. config.yml (or the default, if the key isn't there);
  2. the active preset, if any;
  3. the bot's faction settings.
Active preset If the active preset sets the same key, /pvpbot set writes it to config.yml but the preset's value still wins. The command tells you so: use /pvpbot preset off, or save the preset again with /pvpbot preset save <name>.

Building

Group building: what bots may do to the world's blocks. They only ever break soft natural blocks (dirt, sand, gravel, clay, leaves, undergrowth, cobwebs), never stone, ore, builds or containers.

{{settings:building}}

Detection

Group detection: when a bot notices a target. The multipliers scale the distance you're noticed at: below 1 means you have to be closer to be seen.

{{settings:detection}}
